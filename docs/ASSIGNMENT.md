## Уточнения примеров

- cmd/app и internal показаны как пример. В Python их роли выполняют точки входа и app с четырьмя слоями.
- Практическая часть допускает /health или /api/v1/health, а для сдачи указан второй. Работают оба.
- В пример JSON не включён uptime, но он требуется в практической части. Реализован uptime_seconds.
- Push в main в примере заменён публикацией в lab3 по явному указанию пользователя.

Исправлены URL, зашитый секрет, недостаточные исключения Git и отсутствие документов в корне. Существующий локальный .env дополнен недостающим секретом без изменения других параметров. Сервис отделён от конфигурации. [Проверки](REVIEW.md).
