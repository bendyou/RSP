# Слой доступа к данным

В лабораторной №3 репозиторий не реализован: health-check проверяет процесс и не нуждается в БД. Здесь будут адаптеры Django ORM для моделей CommandX, когда они потребуются следующим заданием. Сервис не должен выполнять HTTP-запросы или читать request.user; контроллер передаёт ему необходимые значения и зависимости.

Не создавайте фиктивные CRUD-заглушки или миграции ради заполнения каталога. Модель будущей реализации нужно сверять с [архитектурой в ветке lab1](https://github.com/bendyou/RSP/blob/lab1/ARCHITECTURE.md) и актуальным `pic_project`.
